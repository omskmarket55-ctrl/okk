# ОКК — кабинет контроля качества

Рабочее место сотрудника контроля качества и кабинет администратора для NPS-обзвона клиентов.

- Клиенты приходят из Битрикс24: когда в сделке появляется дело выбранного типа на сотрудника ОКК.
- Сотрудник видит ФИО и выбранные поля сделки; телефон скрыт, видны две последние цифры.
- Звонок — через UIS из браузера: номер клиента подставляет сервер.
- Анкету администратор собирает сам в конструкторе: NPS, варианты, условия показа, перезвон, рекомендация.
- «Подумает, перезвонить» и «Перезвонить позже» — выбор даты и времени; за 15 минут клиент возвращается
  в очередь со статусом «Повторный звонок», это пишется в историю.
- Рекомендация уходит в Битрикс24 новым лидом. Анкеты хранятся только в кабинете.
- Администратор: полные номера, ссылка на сделку, все ответы клиента, дашборд NPS, роли и права, журнал действий.
- СМС из карточки клиента через подключённый сервис (SMS.ru, SMSC.ru, SMS Aero; «Трубка» — после модерации).

ОКЦ — обзвон загруженной базы номеров с записью на встречу:

- Оператор ставит статус «Готов», «Перерыв» или «Не готов»; карточки делятся поровну между «Готов».
- Итоги звонка: позвонить позднее, есть договорённость, отказ с причиной, согласен на встречу.
- Встреча создаёт сделку в воронке ОКЦ и событие в календаре «Встречи ОП» или «Встречи ОУП».
- Стадия «Встреча состоялась» в Битрикс24 начисляет оператору бонус; вывод — через одобрение администратора.
- Закреплённые карточки открепляются сами, если оператор долго не заходит. Статистика и конверсии по операторам.

## Установка на сервер

Сервер unosystem, рядом с другими проектами. Одна команда от root:

```bash
curl -fsSL https://raw.githubusercontent.com/omskmarket55-ctrl/unosystem-site/main/deploy/okk-bootstrap.sh | sudo bash
```

Скрипт забирает код в `/opt/okk`, создаёт `.env` с секретами, спрашивает вебхук Битрикс24 и ключ UIS
(можно пропустить), собирает контейнеры, включает автообновление из `main` и ночную копию базы, подключает
`okk.unosystem.ru` к общему входному Caddy. В конце показывает пароль администратора — один раз.

Подключение Битрикс24 — `docs/bitrix24-setup.md`, UIS — `docs/uis-setup.md`.

## Разработка

```bash
npm install
cp .env.example .env   # DATABASE_URL, SESSION_SECRET, PHONE_KEY, INITIAL_ADMIN_PASSWORD, DEMO=1
npm run dev            # сервер :3000
npm run dev:web        # фронтенд :5173
```
