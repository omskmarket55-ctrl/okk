# Устройство

```
Битрикс24 ──дело на сотрудника ОКК──▶ /hooks/bitrix (событие) ─┐
    ▲            crm.activity.list раз в 5 минут ──────────────┤
    │                                                          ▼
    │                                    карточка клиента в PostgreSQL (телефон зашифрован)
    │                                                          │
    └──── crm.lead.add (только рекомендации) ◀── анкета ◀── рабочий стол сотрудника
                                                               │
UIS ◀── start.employee_call (номер подставляет сервер) ◀───────┘
 └──▶ /hooks/uis/<секрет>: статус звонка, длительность, записи
```

## Карточка клиента

| Статус | Что значит |
|---|---|
| `queued` | в очереди; `repeat = true` — повторный звонок после перезвона |
| `callback` | ждёт перезвона; за `queue.callbackLeadMinutes` (15) минут до `callback_at` возвращается в `queued` |
| `done` | анкета заполнена |
| `refused` | клиент отказался от опроса (вариант с действием «отказ») |
| `closed` | снята с обзвона вручную |

Открытая карточка закрепляется за сотрудником на 20 минут, чтобы двое не звонили одному клиенту.
Анкета после перезвона дописывается в ту же запись `responses`, ответы прошлой попытки подставляются в форму.

## Анкеты

Черновик правится в `surveys.draft`, публикация создаёт `survey_versions`. Ответ ссылается на версию —
правка анкеты не меняет смысл старых ответов. Варианты ответа могут нести действие: `callback` (нужна дата
перезвона) или `refuse`. Вопрос типа `referral` создаёт лиды; в самих ответах остаются имя и две последние цифры.

## Безопасность

- Вход по логину и паролю (scrypt), сессия — подписанная cookie на 12 часов. Смена пароля или блокировка
  сразу закрывают старые сессии (`session_version`). 5 неудачных входов — пауза 10 минут.
- Изменения в API — только JSON и только со своего адреса (защита от подделки запросов).
- Телефоны — AES-256-GCM, ключ `PHONE_KEY` только в `.env`. Без права номер не уходит в браузер.
- Журнал действий: входы, просмотры номеров, выгрузки, изменения прав, настроек и анкет.
- Ключи сервисов СМС в браузер не отдаются. Записи разговоров остаются в UIS.

# ОКЦ — обзвон базы номеров

Супервайзер загружает номера (файл или вставка), каждый номер — карточка `okc_cards`. Номер шифруется,
дубли отсекаются по HMAC номера (`phone_hash`). Оператор видит две последние цифры, звонит через UIS.

## Статус оператора и выдача карточек

`okc_operator_state`: «Готов» — получает карточки, «Перерыв» — не получает, время считается
(`okc_status_log`), «Не готов» — рабочий день завершён. Карточку выдаёт `nextCard()` по одной:
подошедшие договорённости, свои закреплённые, затем общая база по порядку загрузки (`FOR UPDATE SKIP LOCKED`),
поэтому база делится между операторами в статусе «Готов» поровну.

## Итоги звонка

| Кнопка | Что происходит |
|---|---|
| Позвонить позднее | `later`: закреплена за оператором на 30 дней, снова выдаётся через 60 минут |
| Есть договорённость | `agreement`: звонок в выбранное время, закреплена на 30 дней, раздел «Есть договорённость» |
| Отказ | `refused` с причиной из справочника; вернуть может право `okc.return` |
| Согласен на встречу | `meeting`: контакт и сделка в воронке ОКЦ, событие в календаре ОП/ОУП, для офисной встречи завтра и позже — дело за 3 часа |

Стадии сделок ОКЦ проверяются раз в 5 минут (и по событию ONCRMDEALUPDATE): «состоялась» — `meeting_done`
и бонус оператору по стоимости встречи на этот момент; «не состоялась» — `meeting_failed`, карточка снова
в обзвоне у того же оператора на 30 дней.

## Открепление

Раз в 5 минут `autoRelease()`: закреплённая карточка уходит в общую базу, если закрепление истекло или
оператор не заходил в кабинет: «позвонить позднее» — 5 дней, договорённость — 7, несостоявшаяся встреча — 10.
Сроки — в «Настройки» → «ОКЦ». Супервайзер снимает карточки вручную (одну или все у оператора).

## Бонус

Начисления — `okc_bonus_accruals` (по одному на карточку). Доступно = начислено − заявки на проверке − одобренные.
Заявку одобряет или отклоняет с комментарием право `okc.payouts`; отклонённая сумма возвращается в баланс.
