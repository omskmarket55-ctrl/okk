# Устройство

```
Битрикс24 ──дело на сотрудника ОКК──▶ /hooks/bitrix (событие) ─┐
    ▲            crm.activity.list раз в 5 минут ──────────────┤
    │                                                          ▼
    │                                    карточка клиента в PostgreSQL (телефон зашифрован)
    │                                                          │
    └──── crm.lead.add (только рекомендации) ◀── анкета ◀── рабочий стол сотрудника
                                                               │
UIS ◀── start.employee_call (номер подставляет сервер) ◀───────┘
 └──▶ /hooks/uis/<секрет>: статус звонка, длительность, записи
```

## Карточка клиента

| Статус | Что значит |
|---|---|
| `queued` | в очереди; `repeat = true` — повторный звонок после перезвона |
| `callback` | ждёт перезвона; за `queue.callbackLeadMinutes` (15) минут до `callback_at` возвращается в `queued` |
| `done` | анкета заполнена |
| `refused` | клиент отказался от опроса (вариант с действием «отказ») |
| `closed` | снята с обзвона вручную |

Открытая карточка закрепляется за сотрудником на 20 минут, чтобы двое не звонили одному клиенту.
Анкета после перезвона дописывается в ту же запись `responses`, ответы прошлой попытки подставляются в форму.

## Анкеты

Черновик правится в `surveys.draft`, публикация создаёт `survey_versions`. Ответ ссылается на версию —
правка анкеты не меняет смысл старых ответов. Варианты ответа могут нести действие: `callback` (нужна дата
перезвона) или `refuse`. Вопрос типа `referral` создаёт лиды; в самих ответах остаются имя и две последние цифры.

## Безопасность

- Вход по логину и паролю (scrypt), сессия — подписанная cookie на 12 часов. Смена пароля или блокировка
  сразу закрывают старые сессии (`session_version`). 5 неудачных входов — пауза 10 минут.
- Изменения в API — только JSON и только со своего адреса (защита от подделки запросов).
- Телефоны — AES-256-GCM, ключ `PHONE_KEY` только в `.env`. Без права номер не уходит в браузер.
- Журнал действий: входы, просмотры номеров, выгрузки, изменения прав, настроек и анкет.
- Ключи сервисов СМС в браузер не отдаются. Записи разговоров остаются в UIS.
