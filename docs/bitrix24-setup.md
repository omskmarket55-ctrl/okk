# Подключение Битрикс24

## 1. Входящий вебхук

Битрикс24 → «Разработчикам» → «Другое» → «Входящий вебхук». Права: **CRM (crm)** и **Пользователи (user)**.
Адрес вида `https://портал.bitrix24.ru/rest/1/xxxxxxxx/` — секрет: не пересылайте его в чатах.
`install.sh` спросит его при установке; или впишите в `/opt/okk/.env` как `BITRIX_WEBHOOK_URL` и выполните
`cd /opt/okk && docker compose up -d`.

## 2. Источник сделок

Кабинет → «Настройки» → «Какие сделки попадают в обзвон»:

1. Выберите сотрудника контроля качества — ответственного за дело-триггер.
2. Нажмите «Показать последние дела выбранного сотрудника» и у нужного дела — «Это тип триггера».
   При необходимости уточните тему дела («Тема дела содержит»), воронку и стадии.
3. Включите «Загружать клиентов из Битрикс24» и сохраните. «Проверить сейчас» загрузит дела сразу.

Без исходящего вебхука новые дела забираются раз в 5 минут.

## 3. Мгновенная загрузка (необязательно)

«Разработчикам» → «Другое» → «Исходящий вебхук»: событие **«Добавление дела» (ONCRMACTIVITYADD)**,
адрес `https://okk.unosystem.ru/hooks/bitrix`. Токен приложения из настроек вебхука впишите в `.env`
как `BITRIX_OUTGOING_TOKEN` и перезапустите: `cd /opt/okk && docker compose up -d`.

## 4. Лид по рекомендации

«Настройки» → «Лид по рекомендации»: источник (по умолчанию «По рекомендации»), ответственный, название.
Для связи лида со сделкой рекомендателя можно завести пользовательское поле лида и указать его код.
