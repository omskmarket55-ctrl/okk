# ОКК — заметки для разработки

Кабинет контроля качества: NPS-обзвон клиентов по сделкам Битрикс24. Монорепозиторий на npm workspaces:
`server/` (Fastify + TypeScript + PostgreSQL), `web/` (React + Vite). Устройство — `docs/architecture.md`.

## Команды

- `npm run typecheck` и `npm test` — перед каждым коммитом. Сквозной тест `server/test/flow.test.ts` идёт на
  настоящей PostgreSQL: `TEST_DATABASE_URL=postgres://…/okk_test npm test` (база пересоздаётся целиком).
- `npm run build` — сборка фронтенда и сервера.
- Демо: `DEMO=1` — примерные клиенты и оператор `operator` / `operator-demo`.

## Договорённости

- Интерфейс, комментарии и тексты — на русском.
- Телефоны клиентов и рекомендаций хранятся только зашифрованными (`auth/phone.ts`, ключ `PHONE_KEY`).
  Полный номер уходит в браузер только при праве `phones.view` / `referrals.phones.view`, каждый просмотр — в `audit_log`.
- Анкеты хранятся только у нас. В Битрикс24 из кабинета уходит лишь лид по рекомендации (`bitrix/leads.ts`)
  и, если включено, закрытие дела-триггера.
- Права — каталог в `server/src/auth/permissions.ts`; проверка на сервере через `ctx.need(req, ...права)`.
- Логика анкеты (условия показа, проверка ответов, NPS) — чистый модуль `server/src/surveys/schema.ts`,
  его же импортирует фронтенд. Правка логики — с тестом в `server/test/survey.test.ts`.
- Запросы к Битрикс24 — только через `BitrixClient` (очередь 2 запроса/с, повторы при лимите).
- Новые таблицы — отдельной миграцией в `server/src/db/migrations/NNN_*.sql`.
- Сервер делят несколько проектов: без тяжёлых зависимостей и лишних процессов.
